## 1. Tóm Tắt Giá Trị & Kiến Trúc (Executive Summary)

Subsystem **Obsidian Vault Bridge** kết nối cơ sở tri thức cục bộ Obsidian Vault với Knowledge OS theo nguyên lý **Read-Only Vault Bridge** ([ADR-064](docs/adr/ADR-064-read-only-obsidian-vault-bridge.md)):
1. **Single Source of Truth (SSOT)**: Mọi ghi chú Markdown, cấu trúc thư mục, ảnh và media được lưu giữ và quản lý độc quyền tại Obsidian Vault của người dùng.
2. **Read-Only & Zero Database Bloat**: Knowledge OS chỉ lưu metadata (`Resource` type `md`: `filePath`, `title`, `notes`) trong cơ sở dữ liệu PostgreSQL; không sao chép raw Markdown vào DB.
3. **Hardened Security & Boundary Protection**: 
   - 12-step path guard chặn Path Traversal (`..`, URL encoded `%2e%2e`), từ chối Symbolic Links (`403 SYMLINK_NOT_ALLOWED`), ẩn đường dẫn máy chủ qua placeholder (`[VAULT_ROOT]`).
   - Lọc bỏ mã độc HTML (`<script>`, `<iframe>`, `on*=` handlers) và các scheme URL không an toàn (`javascript:`, `data:`, `vbscript:`, `file:`).
4. **Trải Nghiệm Đọc Thượng Hạng (Superior Reading Experience)**:
   - Trình duyệt thư mục dạng cây (Vault Tree), tìm kiếm toàn văn trong bộ nhớ (In-memory Full-text Search), điều hướng Wiki-Link (`[[Note]]`) có back history, hiển thị file đính kèm đa phương tiện (Attachment streaming), cập nhật thời gian thực (SSE File Watcher), và nhúng nội dung ghi chú đệ quy an toàn (Transclusion `![[Note]]`).

## 2. Chi Tiết Các Giai Đoạn Triển Khai (Phase-by-Phase Breakdown)

### Phase P4.1: Read-Only Obsidian Vault Bridge Backend & Topic-Linked Document Viewer
- **API**: `GET /api/obsidian/vault/status`, `GET /api/obsidian/vault/file?path=<relative-path>`.
- **Bảo mật**: `obsidianPathSanitizer.ts` (12-step guard, 2 MiB file limit, symlink rejection).
- **Trình đọc**: `ObsidianDocumentViewerModal.tsx` đọc on-demand từ Vault, render outline tự động, non-destructive unlink.
- **Commits**:
  - `e36cdf7`: `feat(obsidian): add secure read-only vault bridge backend`
  - `549a1ce`: `feat(obsidian): add topic-linked document viewer`

### Phase P4.2A: Vault Tree Browser & Secure Directory Listing
- **API**: `GET /api/obsidian/vault/tree?path=<relative-dir>`.
- **UI**: `ObsidianVaultBrowserModal.tsx` duyệt cây thư mục (thư mục lên trước, tệp theo sau, ẩn `.obsidian` và `.git`).
- **Wiring**: Nút "Browse Vault" trong `TopicDetail.tsx` cho phép chọn file từ Vault để liên kết vào Topic.
- **Commits**:
  - `4b0083f`: `feat(obsidian): add vault tree endpoint with secure directory listing`
  - `49003a0`: `feat(obsidian): add vault browser modal and TopicDetail wiring`

### Phase P4.2B: In-Memory Full-Text Search
- **API**: `GET /api/obsidian/vault/search?q=<query>`.
- **Index**: Quét đệ quy cấu trúc vault và lưu trữ chỉ mục dưới dạng mảng đối tượng trong bộ nhớ (`buildObsidianVaultIndex`).
- **UI**: Hộp tìm kiếm debounced 300ms trong `ObsidianVaultBrowserModal`, trích xuất snippet thông minh và chấm điểm tương đồng.
- **Commits**:
  - `79d6493`: `feat(obsidian): add in-memory search index and vault search endpoint`
  - `b19bc55`: `feat(obsidian): add full-text search box to vault browser modal`

### Phase P4.2C: Wiki-Link Resolver & In-Place Navigation
- **Syntax**: `[[Note Name]]`, `[[Note Name|Display Text]]`, `[[Note Name#Heading]]`.
- **Resolve Engine**: `ObsidianWikiLinkResolver` (khớp frontmatter `title` trước, tên file sau; bộ nhớ đệm memoized).
- **Navigation**: Nhấp vào Wiki-link sẽ chuyển tài liệu ngay trong modal với thanh điều hướng Lịch sử (Back button).
- **Commits**:
  - `2a6bd02`: `feat(obsidian): add wiki-link resolver and markdown link renderer`
  - `2f7e3b0`: `feat(obsidian): add in-place wiki-link navigation and back history in document viewer`

### Phase P4.2D: Attachment & Media Embed Streaming
- **API**: `GET /api/obsidian/vault/attachment?path=<relative-path>`.
- **Syntax**: `![alt](image.png)`, `![[attachment.png]]`, `![[attachment.png|300x200]]`, `![[document.pdf]]`, `![[video.mp4]]`, `![[audio.mp3]]`.
- **Streaming**: Sử dụng `fs.createReadStream`, nhận diện chuẩn MIME types, header `Cache-Control: immutable`, giới hạn dung lượng 10 MiB cho ảnh và 50 MiB cho tài liệu/video.
- **Commits**:
  - `f6c0fa2`: `feat(obsidian): add attachment streaming endpoint with mime detection and path guard`
  - `816adbc`: `feat(obsidian): add attachment and media embed rendering to markdown viewer`

### Phase P4.2E: Live File Watcher (SSE Auto-Refresh)
- **API**: `GET /api/obsidian/vault/watch?path=<relative-path>` (Server-Sent Events).
- **Engine**: `chokidar` bọc quanh file hiện tại được mở trong Viewer, debouncing 500ms chống atomic writes/rename của Obsidian. Bộ lắng nghe sự kiện theo file đơn lẻ với cơ chế debounce 500ms chống trùng lặp sự kiện lưu file của Obsidian.
- **UI**: Tự động re-fetch nội dung khi file lưu trên đĩa và hiển thị badge `"Đã tự động cập nhật từ đĩa"` trong 3 giây.
- **Commits**:
  - `4e2febf`: `feat(obsidian): add file watcher and sse auto-refresh endpoint`
  - `5b61539`: `feat(obsidian): add sse auto-refresh client in document viewer modal`

### Phase P4.2F: Note Transclusion (`![[Note Name]]` & `![[Note Name#Heading]]`)
- **Syntax**: `![[Note Name]]`, `![[Note Name#Heading]]`, `![[Note Name|Alias]]`.
- **Resolve & Extraction**: `extractSection` trích xuất chính xác phạm vi từ heading được chỉ định đến trước heading đồng cấp/cấp cao hơn.
- **Recursion Guard**: Giới hạn độ sâu `MAX_TRANSCLUSION_DEPTH = 3`, cơ chế `ancestors` phát hiện và triệt tiêu vòng lặp tự nhúng (Circular Reference).
- **HTML5 Clean**: Render khối nhúng phân biệt viền tím (`border-l-4 border-purple-500 bg-purple-50/50`) không gây lỗi lồng thẻ `<div>` trong `<p>`.
- **Commits**:
  - `c5aab04`: `feat(obsidian): add transclusion resolver with circular guard and section extraction`
  - `b884f26`: `feat(obsidian): add transclusion block rendering with XSS sanitize and depth limit`
  - `67ab1c5`: `feat(obsidian): integrate transclusion support in document viewer with pre-fetch`
