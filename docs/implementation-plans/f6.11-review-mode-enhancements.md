## 2. TIÊU CHÍ LOW RETENTION (WEIGHTED SCORING)

```typescript
function isLowRetention(card: FlashcardWithSchedule): boolean {
  const { lapses, easeFactor, retentionRate } = card.schedule;
  
  let score = 0;
  if (lapses >= 2) score += 0.4;
  if (easeFactor <= 2.0) score += 0.3;
  if (retentionRate < 0.6) score += 0.3;
  
  return score >= 0.4;
}
```
